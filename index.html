CreateOrderService.java 
public interface CreateOrderUseCase {
  Order create(CreateOrderCommand command);
}

public class CreateOrderService implements CreateOrderUseCase {
  private final OrderRepository orderRepository;
  private final EventPublisher eventPublisher;

  @Transactional
  @Override
  public Order create(CreateOrderCommand cmd) {
    var order = new Order(new OrderId(UUID.randomUUID().toString()),
        cmd.items(), cmd.total());
    orderRepository.save(order);
    eventPublisher.publish(new OrderCreatedEvent(order.id(), Instant.now()));
    return order;
  }
}

Four Workflows

From greenfield to production — every action follows the same non-negotiable hexagonal rules.

CREATE

Scaffold a complete hexagonal microservice from scratch.

  • Ask developer for options (DB, security, messaging, Docker)
  • Generate domain models, VOs, and events
  • Create inbound/outbound ports and use cases
  • Build REST controllers, JPA adapters, mappers
  • Add ApiResponse, GlobalExceptionHandler, MDC filter
MODIFY

Add features to existing hexagonal microservices.

  • Detect project structure (single/multi-module)
  • Reject non-hexagonal projects → suggest MIGRATE
  • Ask what to add: entity, endpoint, client, messaging
  • Generate in order: Domain → Port → UseCase → Adapter
AUDIT

Critical architecture review with 22+ checks.

  • Architecture scan: 12 grep-based checks (CRITICAL → LOW)
  • Optimization scan: N+1, indexes, wide transactions
  • Production-readiness: Actuator, secrets, Docker, MDC
  • Security scan: @PreAuthorize placement, CSRF, JWT
MIGRATE

Convert traditional layered apps to hexagonal.

  • Pre-flight: assess current layering with grep
  • 10 independent steps — stop at any point
  • Extract domain, create VOs, define ports
  • Wrap services as use cases, create adapters
